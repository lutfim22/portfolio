## Tantangan

Simulasi perangkat terhubung perlu memperhatikan kapabilitas dan navigasi lingkungan tempatnya berjalan. Virtual Home menghadirkan perangkat rumah pintar dan interaksinya pada pengalaman seluler, Family Hub, dan TV.

## Pendekatan

Saya mengembangkan pengalaman web lintas platform untuk simulasi perangkat terhubung dan interaksi pengguna. Pekerjaan ini mencakup penyesuaian perilaku terhadap kapabilitas serta kebutuhan navigasi setiap platform.

Teknologi yang digunakan meliputi JavaScript, TypeScript, React, LitElement, Web Components, dan integrasi WebView. Kontribusi saya berfokus pada pengalaman web di berbagai lingkungan native tersebut.

## Dampak

Pekerjaan saya berkontribusi pada pengalaman simulasi dan interaksi perangkat terhubung di perangkat seluler, Family Hub, dan TV. Kontribusi tersebut berpusat pada penyesuaian interaksi agar sesuai dengan kebutuhan setiap platform.
